# Деньги до зарплаты

Мини-приложение Telegram для Максима и Жени. Один экран отвечает на три вопроса:

- хватит ли денег до следующей выплаты;
- покрыты ли обязательные платежи периода;
- если гибкая статья вышла за лимит, из какой статьи взять.

Зарплата 5-го, аванс 20-го. Месяц делится на два периода: 5-19 и 20-4. Календарь московский.

Бэкенд на Go, экран на React. Таблицу «Бюджет» приложение только читает.

## Локально, без бота и без таблицы

Фикстура повторяет утверждённый прототип ноября: свободно 46 234 ₽, 3 082 ₽ в день, статус «Впритык», темп октября 3 891 ₽ в день.

```bash
go test ./...
go vet ./...

APP_ENV=dev DEV_SKIP_AUTH=1 DATA_SOURCE=fixture go run ./cmd/server
```

В другом терминале:

```bash
cd web
npm install
npm run dev
```

Откройте http://127.0.0.1:5173 . `DEV_SKIP_AUTH` работает только вместе с `APP_ENV=dev` и принимает ровно заголовок `Authorization: tma dev`. В боевом режиме этот заголовок не проходит.

Сборка экрана:

```bash
cd web && npm run build
```

`npm run build` не зашивает dev-обход. Боевой экран шлёт `initData` из Telegram.

## Docker одной командой

Из корня репозитория, в режиме фикстуры (бот не обязателен):

```bash
docker compose up --build
```

Сервис слушает порт 8080. Для семьи задайте переменные из `.env.example` (токен, allowlist, `DATA_SOURCE=sheets`, ключ Google) и поднимите HTTPS, см. ниже.

## BotFather

1. В @BotFather: `/newbot`, сохраните токен в `TELEGRAM_BOT_TOKEN`.
2. Узнайте числовые id Максима и Жени (бот вроде @userinfobot) и запишите их в `TELEGRAM_ALLOWED_USER_IDS` через запятую.
3. Поднимите сервис по HTTPS и запишите адрес в `WEBAPP_URL` (только `https://`, со слэшем в конце не обязательно).
4. Запустите сервис с токеном. На старте бот ставит кнопку меню «Бюджет» на мини-приложение. `/start` отвечает кнопкой «Открыть». Чужим id бот пишет, что он только для семьи, а API отвечает 403.
5. По желанию в BotFather: Bot Settings, Configure Mini App, тот же URL. Прямую ссылку можно сделать через `/newapp`.

Каждый запрос экрана несёт `Authorization: tma <initData>`. Подпись проверяется библиотекой `github.com/telegram-mini-apps/init-data-golang` ключом бота. initData старше 24 часов и поддельная подпись получают 401. Пустой allowlist никого не пускает.

Токен для тестов не нужен: тесты подписывают initData своим ключом.

## Сервисный аккаунт Google

Таблица: `1n_Yp3gHkX-jNZGD5Mn4IYxPtAixZhF6xyXNVurUZrBI` (переменная `BUDGET_SPREADSHEET_ID`).

1. В Google Cloud создайте проект, включите Google Sheets API.
2. Создайте сервисный аккаунт и JSON-ключ.
3. В таблице «Бюджет» нажмите «Поделиться» и дайте этому аккаунту роль читателя. Редактора не давайте: код ходит в API только с scope `spreadsheets.readonly` и вызывает только `values.get`.
4. Положите JSON вне репозитория и укажите путь:

```bash
GOOGLE_APPLICATION_CREDENTIALS=/run/secrets/sa.json
DATA_SOURCE=sheets
```

Либо положите сам JSON в `GOOGLE_SERVICE_ACCOUNT_JSON` (если строка начинается с `{`, это содержимое, иначе это путь к файлу). В compose удобнее смонтировать файл:

```yaml
services:
  app:
    volumes:
      - ./secrets/sa.json:/run/secrets/sa.json:ro
    environment:
      GOOGLE_APPLICATION_CREDENTIALS: /run/secrets/sa.json
      DATA_SOURCE: sheets
```

Чтение кэшируется на `CACHE_TTL` (по умолчанию 3 минуты). Ошибки не кэшируются.

## Что сверить с живой таблицей

Пока это не сверено, `DATA_SOURCE=sheets` может прочитать не те ячейки. Черновик лежит в `config/sheets.yaml`, классификация и даты в `config/budget.yaml`.

Лист «Операции» описан ведущим таблицы, заголовки проверяются:

| Колонка | Заголовок |
| --- | --- |
| A | Дата |
| B | Месяц |
| C | Счёт |
| D | Описание |
| E | Комментарий |
| F | Сумма |
| G | Тип |
| H | Категория банка |
| I | MCC |
| J | Категория бюджета |
| K | Расход (для факта) |
| L | Статус |
| M | Копилка |

Если заголовок не совпадёт, сервис откажется читать лист и напишет, какая колонка разъехалась.

Месячные листы («Октябрь», «Ноябрь», …) в коде не угаданы. Сейчас черновик такой: колонка A категория, B план с зарплаты (5-е), C план с аванса (20-е), D факт, данные со 2-й строки, строки прихода называются «Зарплата» и «Аванс». Это нужно открыть в книге и поправить буквы. Пустая ячейка плана значит «лимит не задан», ноль значит лимит ноль.

Дальше по смыслу, это тоже надо подтвердить:

- Все обязательные платежи прототипа отнесены к периоду зарплаты (5-19). Если что-то платится из аванса, в `config/budget.yaml` поставьте `period: advance`.
- Даты с «~» и «дата ?» заданы в том же файле, не в таблице. Сумма `amount_default` берётся только когда ячейка пустая. В фикстуре она и есть сумма прототипа.
- Аванс в прототипе не задан, `income_defaults.advance` равен 0. Пока строка «Аванс» не найдена, период 20-4 покажет нулевой приход и статус «Нет».
- Факт на экране по умолчанию берётся из колонки факта месячного листа (`fact_source: monthly`). Темп «рублей в день» считается по операциям гибких статей прошлого такого же периода. В фикстуре темп зафиксирован как в прототипе: 3 891 ₽. Если по операциям выйдет другая цифра, не сошёлся набор категорий или окно дат.
- Колонка «Статус» считается оплатой при значениях «оплачено» и «проведено». Написание сверьте.
- Подпись «Школа (вкл. предоплату ноября)» есть только в фикстуре. Из таблицы придёт имя категории.
- Вкладка месяца называется именительным падежом без года («Ноябрь»). Книга на два календарных года в одну вкладку «Декабрь» не лезет.
- Копейки округляются до рубля.

Интернет в конфиге есть, но скрыт, пока в листе нет суммы. Авто, Подарки и Корм питомцам появятся на экране, когда по ним будет план или факт.

## HTTPS

Мини-приложение открывается только по HTTPS.

Caddy рядом с сервисом (`deploy/Caddyfile.example`):

```
budget.example.com {
  reverse_proxy app:8080
}
```

На время настройки подойдёт туннель, например `cloudflared tunnel --url http://127.0.0.1:8080` или ngrok. Адрес туннеля запишите в `WEBAPP_URL` и перезапустите бота, чтобы кнопка меню смотрела на новый URL.

## Переменные

| Переменная | Зачем |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен BotFather, без него бот не стартует |
| `TELEGRAM_ALLOWED_USER_IDS` | id через запятую, пустой список никого не пускает |
| `WEBAPP_URL` | https-адрес мини-приложения, обязателен вместе с токеном |
| `DATA_SOURCE` | `fixture` или `sheets` |
| `BUDGET_SPREADSHEET_ID` | id книги |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | JSON ключа или путь к нему |
| `GOOGLE_APPLICATION_CREDENTIALS` | путь к JSON ключа |
| `APP_ENV` | `prod` или `dev` |
| `DEV_SKIP_AUTH` | `1` только при `APP_ENV=dev` |
| `CACHE_TTL` | сколько держать чтение таблицы, по умолчанию `3m` |
| `ADDR` | адрес HTTP, по умолчанию `:8080` |
| `BUDGET_CONFIG` | `config/budget.yaml` |
| `SHEETS_CONFIG` | `config/sheets.yaml` |
| `FIXTURE_CONFIG` | `config/fixture.yaml` |
| `STATIC_DIR` | каталог собранного экрана |

## Как устроен расчёт

Свободные деньги = плановый приход периода минус все обязательные суммы, включая уже оплаченные. Оплата в прототипе это статус, а не повод вычесть платёж второй раз.

В день = свободные / число дней периода. На экране сумма округлена до рубля. Статус сравнивает точное отношение с темпом прошлого такого же периода:

- «Нет», если свободных меньше нуля;
- «Впритык», если на день выходит строго меньше прошлого темпа;
- «Да» иначе.

Если гибкая статья выше лимита, «Откуда взять» забирает остаток у статей с запасом: сначала у той, где запаса больше. Один и тот же запас не предлагается дважды. Лимит «не задан» перерасходом не считается.

Цвета статуса зафиксированы: зелёный `#2E9E5B`, янтарный `#D99A00`, красный `#D64545`. Фон и текст берутся из `themeParams` Telegram.
