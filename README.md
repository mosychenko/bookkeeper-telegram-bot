# Деньги до зарплаты

Мини-приложение Telegram для Максима и Жени. Один экран отвечает на три вопроса:

- хватит ли денег до следующей выплаты;
- покрыты ли обязательные платежи периода;
- если гибкая статья вышла за лимит, из какой статьи взять.

Зарплата 5-го, аванс 20-го. Месяц делится на два периода: 5-19 и 20-4. Календарь московский.

Бэкенд на Go, экран на React. Таблицу «Бюджет» приложение только читает.

## Локально, без бота и без таблицы

Фикстура повторяет утверждённый прототип ноября: свободно 46 234 ₽, 3 082 ₽ в день, статус «Впритык», темп октября 3 891 ₽ в день.

```bash
go test ./...
go vet ./...

APP_ENV=dev DEV_SKIP_AUTH=1 DATA_SOURCE=fixture go run ./cmd/server
```

В другом терминале:

```bash
cd web
npm install
npm run dev
```

Откройте http://127.0.0.1:5173 . `DEV_SKIP_AUTH` работает только вместе с `APP_ENV=dev` и принимает ровно заголовок `Authorization: tma dev`. В боевом режиме этот заголовок не проходит.

Сборка экрана:

```bash
cd web && npm run build
```

`npm run build` не зашивает dev-обход. Боевой экран шлёт `initData` из Telegram.

## Docker одной командой

Из корня репозитория, в режиме фикстуры (бот не обязателен):

```bash
docker compose up --build
```

Сервис слушает порт 8080. Это локальный запуск без HTTPS. Команда собирает образ на той машине, где она запущена. На VPS смотрите раздел «Деплой на VPS»: там образ приезжает готовым, а Caddy сам получает сертификат.

## BotFather

1. В @BotFather: `/newbot`, сохраните токен в `TELEGRAM_BOT_TOKEN`.
2. Узнайте числовые id Максима и Жени (бот вроде @userinfobot) и запишите их в `TELEGRAM_ALLOWED_USER_IDS` через запятую.
3. Поднимите сервис по HTTPS и запишите адрес в `WEBAPP_URL` (только `https://`, со слэшем в конце не обязательно).
4. Запустите сервис с токеном. На старте бот ставит кнопку меню «Бюджет» на мини-приложение. `/start` отвечает кнопкой «Открыть». Чужим id бот пишет, что он только для семьи, а API отвечает 403.
5. По желанию в BotFather: Bot Settings, Configure Mini App, тот же URL. Прямую ссылку можно сделать через `/newapp`.

Каждый запрос экрана несёт `Authorization: tma <initData>`. Подпись проверяется библиотекой `github.com/telegram-mini-apps/init-data-golang` ключом бота. initData старше 24 часов и поддельная подпись получают 401. Пустой allowlist никого не пускает.

Токен для тестов не нужен: тесты подписывают initData своим ключом.

## Сервисный аккаунт Google

Таблица: `1n_Yp3gHkX-jNZGD5Mn4IYxPtAixZhF6xyXNVurUZrBI` (переменная `BUDGET_SPREADSHEET_ID`).

1. В Google Cloud создайте проект, включите Google Sheets API.
2. Создайте сервисный аккаунт и JSON-ключ.
3. В таблице «Бюджет» нажмите «Поделиться» и дайте этому аккаунту роль читателя. Редактора не давайте: код ходит в API только с scope `spreadsheets.readonly` и вызывает только `values.get`.
4. Положите JSON вне репозитория и укажите путь:

```bash
GOOGLE_APPLICATION_CREDENTIALS=/run/secrets/sa.json
DATA_SOURCE=sheets
```

Либо положите сам JSON в `GOOGLE_SERVICE_ACCOUNT_JSON` (если строка начинается с `{`, это содержимое, иначе это путь к файлу). На VPS ключ в репозиторий не кладётся: путь на хосте пишется в `GOOGLE_SA_FILE`, скрипт монтирует файл в контейнер как `/run/secrets/sa.json`.

Чтение кэшируется на `CACHE_TTL` (по умолчанию 3 минуты). Ошибки не кэшируются.

## Деплой на VPS

Сервер — Debian 13. Образ собирается на Mac и копируется готовым: на VPS нет сборки npm и Go. Swap для сборки на сервере не нужен. Рабочему контейнеру хватает 1 ГБ.

Сначала A-запись `dozp.ru` на IP сервера. Порты 80 и 443 свободны, их же открыть в файрволе.

На Mac, в том числе на Apple Silicon, из каталога репозитория:

```bash
bash deploy/push-image.sh user@vps
```

Скрипт собирает образ с `--platform linux/amd64` и передаёт его командой `docker save | gzip | ssh user@vps 'gunzip | docker load'`. Образ arm64 с Apple Silicon на обычном Debian не запустится, поэтому платформа по умолчанию `linux/amd64`. Имя образа по умолчанию `dengi:latest`. Явно:

```bash
bash deploy/push-image.sh user@vps --platform linux/amd64 --image dengi:latest
```

К моменту загрузки на сервере уже нужен Docker: приём образа выполняет `docker load`. Если Docker ещё не стоит, скрипт установки ниже поставит его и остановится, пока образ не приедет с Mac.

На Debian 13, из каталога репозитория:

```bash
sudo bash deploy/vps-install.sh dozp.ru you@example.com
```

Скрипт ставит Docker и плагин Compose, если их нет, проверяет 80 и 443, создаёт `.env` из `.env.example`, пишет домен и `WEBAPP_URL=https://dozp.ru`, печатает пустые `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_USER_IDS`. Если образа `dengi:latest` (или значения `APP_IMAGE`) нет, скрипт останавливается и просит сначала запустить `deploy/push-image.sh` на Mac. Контейнеры стартуют из уже загруженного образа, без сборки. Caddy сам получает сертификат Let's Encrypt. Сертификаты лежат в томе `caddy_data`. Порт приложения на сервере слушает только `127.0.0.1:8080`. Каталог `config/` с диска сервера монтируется в контейнер только для чтения. Таблица по-прежнему только читается.

Для первой проверки оставьте `DATA_SOURCE=fixture` (так и стоит в примере). Ключ Google не нужен. Откроется экран прототипа. Без Telegram он попросит открыть мини-приложение из бота.

Проверка:

```bash
curl -fsS https://dozp.ru/api/health
```

Дальше в `.env`: токен, id семьи, `DATA_SOURCE=sheets` и `GOOGLE_SA_FILE` (путь к JSON вне репозитория, например `/root/dengi-sa.json`). Запустите скрипт установки ещё раз.

Обновление на сервере:

```bash
sudo bash deploy/vps-update.sh
```

Это `git pull` и перезапуск уже загруженного образа. Так подхватываются compose, Caddyfile и `config/`. Образ приложения скрипт не пересобирает. Новый код и экран сначала отправьте с Mac тем же `deploy/push-image.sh`, затем запустите обновление на сервере.

## Как читается таблица

Раскладка сверена с книгой 2026-11-04. Если заголовок разъедется, сервис откажется читать лист и напишет, какая ячейка не совпала.

Лист «Операции»: колонка K «Расход (для Факт)», колонка L «Статус», колонка M «Копилка (движение)». Оплатой считается только «Выполнено».

Месячный лист («Октябрь», «Ноябрь», …): две строки заголовка. План с зарплаты в колонке C, план с аванса в D, факт в E. Имя категории в A с префиксом «- ». У кредитов имя в колонке B, перевод строки схлопывается («Кредит Максим»). Плановый доход это строка 3 «Доход»: C3 зарплата, D3 аванс. Фактический доход это J3 «Зарплата (вкл. отпускные)» и J4 «Аванс». Ноль в этих ячейках это известный ноль. Строка 44 «Сбережения (Копилка 10%)» тоже читается, она ниже сумм строк 5–42.

Пустая ячейка плана значит «в этом периоде статьи нет». Сумма периода берётся из своей колонки: одна статья может быть и в C, и в D.

Какие статьи обязательные, гибкие и редкие, и в какие дни они списываются, задано в `config/budget.yaml` по разметке ведущего таблицы. Редкая статья считается гибкой, но на экране появляется только если в этом периоде есть план или факт. Строки «Кредиты:» и «Карманные» это заголовки групп. Страховка ипотеки 300 входит в строку «Ипотека». Факт на экране берётся из колонки E (`fact_source: monthly`). Подпись «Школа (вкл. предоплату ноября)» есть только в фикстуре. Вкладка месяца называется именительным падежом без года. Копейки округляются до рубля. Код таблицы только читает.

| `GOOGLE_SERVICE_ACCOUNT_JSON` | JSON ключа или путь к нему |
| `GOOGLE_APPLICATION_CREDENTIALS` | путь к JSON ключа на машине, где запущен процесс |

| `APP_IMAGE` | тег готового образа, по умолчанию `dengi:latest` |

## Как устроен расчёт

Свободные деньги = плановый приход периода минус все обязательные суммы, включая уже оплаченные. Оплата в прототипе это статус, а не повод вычесть платёж второй раз.

В день = свободные / число дней периода. На экране сумма округлена до рубля. Статус сравнивает точное отношение с темпом прошлого такого же периода:

- «Нет», если свободных меньше нуля;
- «Впритык», если на день выходит строго меньше прошлого темпа;
- «Да» иначе.

Если гибкая статья выше лимита, «Откуда взять» забирает остаток у статей с запасом: сначала у той, где запаса больше. Один и тот же запас не предлагается дважды. Лимит «не задан» перерасходом не считается.

Цвета статуса зафиксированы: зелёный `#2E9E5B`, янтарный `#D99A00`, красный `#D64545`. Фон и текст берутся из `themeParams` Telegram.
